# 🎨 DoodleTales

DoodleTales is an interactive AI storytelling website that turns children's drawings into personalized stories.

## ✨ Features

* 📸 Capture drawings using your camera
* 🤖 Use Gemini AI to understand drawings and create stories
* 📖 Build multi-chapter adventures
* 💭 Choose what happens next in the story
* 🔊 Listen to stories with text-to-speech narration
* 📄 Save completed stories as PDF
* 🎨 Kid-friendly hand-drawn UI

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Gemini API
* Vercel
* jsPDF

## 🚀 How It Works

1. Draw a picture.
2. Capture the drawing with the camera.
3. Gemini analyzes the drawing and creates a story.
4. Choose what happens next.
5. Continue building the adventure.
6. Finish and save the story as a PDF.

## 🎯 Use Case

DoodleTales makes storytelling more interactive by combining children's creativity with AI. It can be used for creative learning, entertainment, and encouraging imagination.
